# v4: реакция головы при непрерывном исходном idle

26 октября 2026. Кандидат ожидает художественного принятия. Предыдущая проба с остановкой хвоста и паузой отвергнута пользователем.

Хвост теперь всегда продолжает исходный цикл 1→2→3→4→5→1, по 264 мс на фазу, как в приложении. «Погладить» меняет только голову: 0→1→2→1→0 пикселей вниз в моменты 0/132/264/1056/1188 мс от клика. Хвост движется и во время удержания головы. Клик и окончание жеста не сбрасывают фазу или остаток времени текущего tail-кадра. Общая кнопка паузы намеренно останавливает весь просмотр; продолжение сохраняет остаток времени. Новая реакция запускается только кнопкой.

`poses/` содержит 15 PNG 46×37: три положения головы для каждой из пяти исходных idle-фаз. При head=0 весь PNG RGBA-точно совпадает с текущим исходным idle. При head>0 основой остаётся та же текущая исходная фаза; вне области головы её пиксели не меняются. Поэтому голова входит в текущую позу и возвращается в неё без подмены тела или сброса хвоста. Небольшие исходные изменения текстуры лап между idle-фазами сохранены; поглаживание не изменяет лапы относительно текущего исходного кадра.

Основная область головы `[24,4,46,27)` переносится целочисленно, без вращения или ресайза. Мягкая левая граница `[22,4,24,23)` переносится отдельно поверх сохранённой спины y≥23. ROI изменений головы: `[24,4,46,29)` и `[22,4,24,25)`. Прежние исправления остаточного шипа x23,y19..22 и лишней очистки строки шеи y28 сохранены. Закрытый глаз — два исходных цветовых пикселя, как в предыдущей пробе. Уши следуют за головой, отдельного складывания ушей нет.

`../preview.html` показывает непрерывный idle и реакцию по клику; оригинал слева можно включать отдельно. `motion.js` хранит один активный elapsed для хвоста и отдельное время клика для головы. Нет отдельного tail-цикла поглаживания, палиндрома, возврата к фазе 0, завершающей паузы или автоповтора. Cache revision: `continuous-tail-20261026`.

`frames/` и APNG — один демонстрационный жест, начатый в idle1: восемь кадров, 1584 мс. Длительности 132/132/264/264/264/132/132/264 мс — объединение моментов смены головы и обычных фаз хвоста. Последняя фаза длится обычные 264 мс, без дополнительного удержания. APNG 1×/8× имеют `loop=1` и после одного показа останавливаются; интерактивный HTML продолжает исходный idle. Сам APNG не может продолжать интерактивный idle после окончания файла.

`build_preview.py` воспроизводит все PNG/APNG и контактные листы. `contact-sheet.png` показывает все 15 поз; `contact-{light,dark,checker}-{right,left}.png` — те же позы на трёх фонах в обе стороны. `original-reference-sheet.png` сохраняет исходные idle/lie/walk для сравнения.

Проверки:

- `verify_review.py`: все 15 сохранённых поз, полный перенос головы с мягкой alpha, шея и левый край, точность вне ROI и лап относительно каждой текущей исходной фазы, head0 exact для всех пяти фаз, все восемь PNG/APNG и фактические длительности/`loop=1`, неизменность всех 30 исходных PNG по SHA256.
- Реальные сохранённые плохие PNG с щелью шеи и шипом по-прежнему проваливают соответствующие regression. Сравнения: `gap-before-after-backgrounds.png`, `spike-before-after-backgrounds.png`.
- `node verify_motion.js`: клик во всех пяти фазах с остатками 0/63/263 мс, независимые изменения головы, выход, пауза и второй клик без сброса хвоста.

Runtime и EXE не менялись и не запускались. Browser QA недоступен; проверки времени выполнены без браузера, художественное принятие пользователем ещё не получено.
