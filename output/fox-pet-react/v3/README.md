# v3: точечная правка оригинального глаза

Статус: candidate pending user review. Пользователь явно разрешил редактировать копии оригинальных кадров скриптом; генерации v1/v2 отвергнуты. В v3 image_gen не использован.

Источник: `assets/sprites/fox/idle/frame_1.png`, SHA256 `e0c567c531a82212dd429356c54e8d958dcfad594ff552b666856e2f372f54ce`. Скрипт `build_preview.py` читает этот файл и сохраняет только новые файлы в своей папке.

Все шесть кадров имеют исходный размер 46 × 37 и исходную пиксельную сетку. ROI: `[33,17,35,19)` — x 33–34, y 17–18, координаты с нуля, правый и нижний края исключены. Фактически меняются только `(33,17)` и `(34,17)`; нижняя тёмная строка глаза сохраняется как закрытое веко. Для полузакрытого состояния цвета берутся из соседних пикселей `(35,17)` и `(36,17)`; для закрытого — `(32,17)`. Новые цвета не вычисляются.

Последовательность: original → half → closed → closed hold → half → original. Длительности: 180/90/180/260/90/300 мс. Это мягкое моргание, пока не законченная выразительная анимация поглаживания. Уши специально не изменены.

Проверено скриптом: alpha всех пикселей неизменна; вне ROI RGBA совпадает бит в бит; первый и последний кадры RGBA-точно совпадают с оригиналом; сохранённые PNG после декодирования совпадают с рабочими кадрами. PNG могут иметь другой файловый SHA256 из-за перекодирования, поэтому совпадение проверяется по RGBA. Подробности: `verification.json`.

Якорь лап совпадает по построению: нижняя плотная строка y=36, центр нижней полосы при alpha≥128 — x=26,5. Ни одна координата тела не изменена, масштаб всех кадров равен 1. Main preview показывает фиксированный original и тот же холст пробника без обрезки/fit; по умолчанию пауза, есть выбор кадра, проигрывание и зеркальный показ. Браузер здесь недоступен, browser visual pass не заявлен.
