# Проверка одноуровневого меню

Текущее изменение касается native Qt popup: все действия, выбор «Панель / Кольцо» и служебные команды доступны непосредственно, без «Ещё → Приложение». Фон панели рисуется явно; у кольца прозрачны только промежутки, а нижняя область команд имеет непрозрачный фон. При недостатке рабочей области применяется компактная раскладка с прокруткой, сохранённый выбор кольца не меняется. В обычном кольце профиль размещается у исходной точки курсора с ограничением по краям экрана.

Двойной клик **MENU_E2E.cmd** запускает тесты исходников через проектный Qt6 Python. Уже запущенное приложение, его EXE, реестр и база пользователя не изменяются. Каждый запуск создаёт отдельную папку `reports/verification/<UTCstamp>-menu-e2e` с summary.json, логами, JUnit XML и PNG. Скрипт последовательно проверяет масштабы 100%, 150%, 200% в отдельных процессах; после успешных целевых тестов запускает полный pytest. Ничего не устанавливает и не собирает.

Проверяются настоящий ПКМ по PetWindow, поглаживание/сердечки, сон/пробуждение, включение/выключение постоянного слежения, мяч, открытие настроек, скрытие, сохранение стиля и закрытие popup других питомцев. Отдельно проверяются RU/EN, обе темы, длинное имя с разметкой, реальные размеры текста, непересечение целей, alpha/color фактически нарисованного фона, отрицательные экраны и тесные рабочие области. PNG создаются из Qt, не из HTML. Все tests используют memory backend и временные данные через tests/conftest.py.

Быстрый снимок без тестов: **RENDER_MENU.cmd**, четыре PNG в `output/menu-concepts/native-current`. Старые HTML-концепции описывают предыдущий дизайн и не являются доказательством исправления текущего native popup.
